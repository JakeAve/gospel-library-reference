# gospel-library-reference

## Design system

Any UI work (components, styles, `index.html`) follows
[.claude/rules/design-system.md](.claude/rules/design-system.md): mobile first,
ink blue as the only accent, `rem`-only font sizes, glass on floating chrome
only, and one bottom sheet for every secondary view. Read it before touching the
UI. It loads automatically when you edit `.tsx`/`.css` files.
